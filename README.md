# Grupo ANBA — Sitio web

Sitio estático (HTML + CSS + JS, sin dependencias) de Grupo ANBA: ANBA Inversiones y ANBA Propiedades.

## Estructura
- `index.html` — contenido de la página
- `styles.css` — estilos
- `main.js` — menú, galería, formulario. Al inicio está `CONTACTO` para cargar WhatsApp y email.
- `assets/img/` — logo y renders

## Publicar con GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → elegir la rama y la carpeta `/ (root)`.

## Pendiente
- WhatsApp, email y dirección completa
- Ficha técnica de Tejedor 263 (unidades, entrega, localidad)
- Nombre, ubicación e información de la torre
- Fotos de obras terminadas
